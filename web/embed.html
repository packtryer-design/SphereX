Put SpotX on your page

One <iframe> shows a live SpotX view: real SPHEREx visits, with the header hidden. Pick an example, then copy the code underneath.

Code



    
Options

    

      
o=orionWhich object. Any id from the catalog, such as orion, ring, wise-0855 or barnards-star.

      
ra=&dec=&fov=&name=Any other position instead, in degrees.

      
view=sequence, blink, side, swipe, diff or rgb (colour-time).

      
a=1&b=3Which two visits to compare (numbered from 1, oldest first).

      
tab=explore (default) or spectrum. The tab bar is hidden when embedded.

      
embed=1Hides the header and tabs, so only the viewer shows.

    

    
Any view in SpotX is already a link: open it, set it up the way you like, then add &embed=1 to the address.
